## 📋 Description
Spaced repetition flashcard system with a pre-loaded FAANG DSA deck (80 cards) and ESL vocabulary deck (60 cards).

## ✨ Features
- Spaced repetition scheduling (SM-2 algorithm)
- FAANG DSA deck: 80 cards across 10 topics
- ESL Vocabulary deck: 60 essential words
- Retention stats and review history
