# 🏋️ Agent #91 — Coder's Workout Split Planner

> Finally, a workout plan that understands you sit for 8 hours a day.

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

## 🔴 Live: https://hhanng.github.io/agent-91-workout-split-planner/

## Features
- 6 pre-built splits (2-day to 6-day PPL, mobility-only)
- Weekly calendar with drag-free exercise scheduling
- Exercise library with muscle group & equipment filters
- Recovery routines for wrist, neck, hips, and eyes
- 20-20-20 eye strain timer

## Tech
Single-file HTML app — no build step, no dependencies, no external APIs. All state persisted in localStorage.
