# ⚛️ Agent #92 — React Component Playground

> Build, test, and learn React components — right in your browser.

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

## 🔴 Live: https://hhanng.github.io/agent-92-react-component-playground/

## Features
- Live JSX editor with Ctrl+Enter to run
- 10 pre-built components (Button, Modal, Toggle, etc.)
- 5 React patterns (useState, useEffect, custom hooks, lifting state)
- Hooks reference & 15 interview Q&As

## Tech
Single-file HTML app — React 18 + Babel standalone loaded in srcdoc iframe for safe JSX execution. No build step required.
