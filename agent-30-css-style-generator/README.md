# CSS Style Generator

Pick a UI component and a vibe, and instantly get beautiful, production-ready CSS with a live preview — no design skills required.

## Features

- Choose from common components (buttons, cards, forms, nav bars, and more)
- Describe a vibe or aesthetic and let Gemini handle the styling
- Live preview renders your generated CSS in real time
- One-click copy to grab the code and drop it into your project

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Select a component type from the dropdown
4. Describe the style you want (e.g., "glassmorphism dark mode" or "retro 80s neon")
5. Click Generate and preview your CSS instantly

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
