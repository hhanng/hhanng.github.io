# Agent #57 - Pronunciation & Accent Trainer

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

**Live:** https://hhanng.github.io/agent-57-pronunciation-accent-trainer/

---

## Features

- 🔤 **IPA Phoneme Guide** — 44 sounds (15 vowels, 24 consonants, 5 diphthongs) with descriptions, example words, and common spellings
- 🌀 **40 Tongue Twisters** — grouped by target sound, filterable by pace (slow/medium/fast), mark as practiced
- 📋 **100 Commonly Mispronounced Words** — phonetic spelling, common mistake, tip, and example sentence; searchable
- 🎯 **Pronunciation Quiz** — 20 questions, pick the correct phonetic spelling from 4 choices, with missed-word review

## Tech Stack

- Vanilla HTML / CSS / JS — single file, no dependencies, no API key
- localStorage (`pron57_` prefix) for all persistence
