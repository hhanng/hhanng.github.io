# Mandala Pattern Designer

**Category:** Art & Creative

Describe a mood or aesthetic, and watch a unique mandala bloom on an HTML5 canvas — AI sets the symmetry, color palette, and intricate layering in real time.

## Features

- Natural-language mood input (e.g., "calm ocean", "fiery sunset") drives the entire design
- Real-time canvas rendering with adjustable symmetry (6 to 24 petals)
- AI-selected color palette and layer complexity based on your description
- Download the finished mandala as a PNG with one click

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Type a mood, theme, or color feeling into the prompt box (e.g., "peaceful forest after rain").
4. Click **Design Mandala** and watch it render on the canvas.
5. Adjust the symmetry slider to refine the look, then hit **Download** to save your artwork.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- HTML5 Canvas API
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
