# Agent #58 - US Teen Social Survival Guide

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

**Live:** https://hhanng.github.io/agent-58-us-teen-social-survival-guide/

## Features

- 📚 **8 Topic Cards** — Making Friends, Dating & Relationships, Social Media, Handling Drama, Peer Pressure, School Cliques, Talking to Adults, Self-Confidence
- 📖 **Detailed Guides** — 6-8 practical tips, Do's & Don'ts, and a real-life scenario with advice for each topic
- 🎭 **20 Interactive Scenarios** — "What would you do?" situations with A/B/C choices and reflection-based feedback
- ✅ **30 Social Confidence Challenges** — Trackable checklist with localStorage persistence and a live progress bar

## Tech

Single-file HTML — all CSS and JS inline, no external dependencies, no APIs.
