# AI Chatbot Builder Guide

An interactive 8-step tutorial that walks you through building and deploying your own Gemini-powered chatbot from scratch.

## Features

- Step-by-step guided tutorial covering setup, coding, and deployment
- Syntax-highlighted code examples powered by highlight.js
- Live Gemini API integration so you can test concepts as you learn
- Beginner-friendly explanations with copy-paste snippets for each step

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Follow the tutorial steps in order (1 through 8)
4. Copy the code snippets and experiment with each concept
5. Deploy your finished chatbot using the instructions in step 8

## Tech Stack

- Gemini API (Google AI)
- highlight.js (syntax highlighting)
- Vanilla HTML, CSS, JavaScript
