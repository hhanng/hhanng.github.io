# Basketball English Vocab

A bilingual EN/VI basketball vocabulary app for teen players — learn the game's language with flashcards, quizzes, a word search, and a personal vocab book.

## Features

- Bilingual flashcards covering positions, plays, stats, and game situations
- Fill-in-the-blank quiz to test your basketball vocabulary in context
- Word search puzzle with basketball terms hidden in the grid
- Personal vocab book to save and review the words that matter most to you

## How to Use

1. Open `index.html` in your browser (no API key needed — fully standalone)
2. Browse flashcards to learn key basketball terms in English and Vietnamese
3. Take the fill-in-the-blank quiz to test what you've learned
4. Try the word search for a fun vocabulary challenge
5. Add words to your personal vocab book for focused review

## Tech Stack

- Vanilla HTML, CSS, JavaScript
- No external API required — works completely offline
