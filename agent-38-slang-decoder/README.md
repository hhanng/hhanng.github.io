# American Slang Decoder

A bilingual EN/VI slang guide for Vietnamese teens — decode American slang with definitions, examples, context, and a cringe-o-meter rating.

## Features

- Bilingual explanations in both English and Vietnamese
- Cringe-o-meter rating shows how cool vs. cringy each term actually is
- Usage examples and context so you know exactly when to use it
- Ask about any slang term or browse trending words

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Type any slang term or phrase you've heard (e.g., "no cap", "rizz", "slay")
4. Get the full bilingual breakdown with cringe-o-meter rating
5. Share with friends or save favorites for later review

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
