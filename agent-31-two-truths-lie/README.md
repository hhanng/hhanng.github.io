# Two Truths & a Lie

AI-generated party game sets on any topic — or paste your own statements and let Gemini polish them into a perfect round.

## Features

- Generate ready-to-play Two Truths & a Lie sets on any topic you name
- Paste your own statements and get AI-polished, convincing versions
- Adjustable difficulty levels from obvious to fiendishly tricky
- Great for icebreakers, classrooms, parties, and team building

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Type a topic (e.g., "ancient Egypt" or "Taylor Swift") and click Generate
4. Or paste your own three statements and click Polish
5. Share the set and challenge your friends to spot the lie

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
