# Basic Conversation Practice

**Category:** Mom's English

A bilingual AI chat partner designed for Vietnamese beginners learning English. Practice natural conversations with voice input, gentle hints, and friendly corrections in real time.

## Features

- AI conversation partner that keeps replies at a beginner-friendly level
- Voice input support so you can speak your answers out loud
- Hint button reveals a suggested response in Vietnamese when you're stuck
- Gentle in-line corrections explain mistakes without breaking the flow

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Pick a conversation topic (greeting, shopping, asking directions, etc.).
4. Type or speak your reply in English — the AI responds naturally.
5. Use the **Hint** button for Vietnamese guidance, and review any corrections at the end.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- Web Speech API for voice input
- No build step — open and go
