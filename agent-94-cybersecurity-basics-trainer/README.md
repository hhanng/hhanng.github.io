# 🔐 Agent #94 — Cybersecurity Basics Trainer

> Level up your security knowledge with hands-on challenges and OWASP deep-dives.

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

## 🔴 Live: https://hhanng.github.io/agent-94-cybersecurity-basics-trainer/

## Features
- 10 interactive challenges: Caesar cipher, hash ID, SQL injection spotter, password entropy, Base64, binary/hex
- Full OWASP Top 10 (2021) with real breach examples and vulnerable vs. safe code
- 20 security tools with type, rating, and FAANG relevance notes
- 20 interview Q&As with know/review tracking

## Tech
Single-file HTML app — all challenges run client-side with pure JS. No server, no external APIs.
