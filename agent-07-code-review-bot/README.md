# Code Review Bot

**Category:** AI Dev

Get instant senior-developer-level feedback on your code. Paste any snippet and receive a quality score, a prioritized list of issues, and a polished fixed version — all in one shot.

## Features

- Holistic quality score (0–100) with a brief rationale
- Ranked issue list covering readability, performance, security, and best practices
- Auto-generates a corrected version of your code with inline comments
- Supports any language — JavaScript, Python, Go, Rust, SQL, and more

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Paste your code into the editor panel.
4. Select the programming language from the dropdown (or leave it on auto-detect).
5. Click **Review** and explore the score, issues, and improved version tabs.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
