# Binary Search Masterclass

An interactive deep-dive into Binary Search — learn patterns, study templates, and practice problems at 3 difficulty levels.

## Features

- 6 core binary search patterns: Classic, First/Last Occurrence, Search in Rotated Array, Search Answer Space, Infinite Array, Matrix Search
- Pattern breakdown with "When to use" and a reusable code template for each
- Difficulty-tagged practice problems (Beginner / Intermediate / Advanced) with hints and full approach reveal
- Built-in reference card and complexity cheat sheet
- Zero dependencies — runs entirely in the browser

## How to Use

1. Open `index.html` in your browser (or visit the live site)
2. Browse patterns on the home tab — click any card to dive in
3. Study the code template, then work through the practice problems
4. Toggle hints when stuck; reveal the full approach when ready

## Tech Stack

- Vanilla HTML + CSS + JavaScript
- highlight.js for code syntax highlighting
- No build step, no API key
