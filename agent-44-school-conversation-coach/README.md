# School Conversation Coach

AI-generated scripts and turn-by-turn practice for real school conversations — making friends, asking teachers questions, and handling conflict gracefully.

## Features

- Pre-loaded situations: meeting new classmates, office hours, group projects, conflict resolution
- Set your English level and get a script matched to your comfort zone
- Turn-by-turn practice mode where Gemini plays the other person
- Tips on tone, body language cues, and culturally appropriate phrasing

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Pick a conversation situation from the menu
4. Set your English level (beginner, intermediate, or advanced)
5. Read through the example script, then enter Practice Mode to try it yourself

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
