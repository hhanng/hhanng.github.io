# LinkedIn Message Generator

Generate polished LinkedIn messages in 4 types — connection request, follow-up, thank-you, and referral ask — with 3 Gemini-written variants each, a 300-character badge, and a tips panel to keep things professional.

Part of the [hhanng.github.io](https://hhanng.github.io) agent portfolio · Career

---

## What It Does

- Supports 4 message types: Connection Request, Follow-Up, Thank-You Note, and Referral Ask
- Generates 3 distinct variants per message type so you can pick the tone that fits
- Character count badge on each variant keeps you within LinkedIn's 300-character connection limit
- Built-in tips panel with best practices for each message type to help you land the reply

## How to Use

1. Open `index.html` in your browser (or visit the live demo from the portfolio)
2. Select the message type you need from the tab bar
3. Fill in the context (recipient's name, role, company, how you found them, etc.)
4. Click **Generate Messages**
5. Compare the 3 variants — the badge shows character count at a glance
6. Copy your favorite and send it directly from LinkedIn

## Tech Stack

- HTML / CSS / Vanilla JavaScript
- [Gemini API](https://ai.google.dev/) (gemini-2.0-flash) for message generation
- No build step — runs entirely in the browser
