# Agent #56 - Vocabulary Builder US High School

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

**Live:** https://hhanng.github.io/agent-56-vocabulary-builder-us-high-school/

---

## Features

- 🗂 **8 word categories** — SAT Words, Academic, Literary Terms, Science, History, Math, Modern Slang, Power Words
- 🃏 **200 flashcards** with flip animation — definition, part of speech, synonyms, example sentence
- 🎯 **4 quiz modes** — Definition Match, Fill in the Blank, Synonym Match, Sentence Context
- 📊 **Progress tracking** — mastered words per category, quiz history, best score

## Tech Stack

- Vanilla HTML / CSS / JS — single file, no dependencies, no API key
- localStorage (`vocab56_` prefix) for all persistence
