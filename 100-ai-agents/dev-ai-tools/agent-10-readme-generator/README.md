# README Generator

**Category:** AI Dev

Generate a professional, badge-adorned GitHub README in seconds. Describe your project, pick a style, and preview the formatted output live before you copy or download.

## Features

- Produces a complete README with title, description, features, installation, usage, and contributing sections
- Auto-suggests relevant shields.io badges (language, license, version, build status)
- Live Markdown preview alongside the raw source
- One-click copy or download as `README.md`

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Fill in your project name, a short description, and the tech stack used.
4. Choose a README style (minimal, standard, or detailed).
5. Click **Generate**, review the live preview, then copy or download the file.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
