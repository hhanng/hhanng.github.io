# Bug Explainer

**Category:** AI Dev

Paste your buggy code and error message, pick your experience level, and get a plain-English explanation of the bug plus a step-by-step fix — written specifically for you.

## Features

- Accepts code + error message together for a full-context diagnosis
- Explanation adapts to your level: Beginner, Intermediate, or Advanced
- Step-by-step fix walkthrough so you learn the reasoning, not just the answer
- Highlights the exact line(s) causing the problem

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Paste your buggy code in the top panel and the error message below it.
4. Choose your experience level from the selector.
5. Click **Explain Bug** and read through the diagnosis and fix.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
