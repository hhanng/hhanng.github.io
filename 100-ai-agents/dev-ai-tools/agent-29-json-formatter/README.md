# JSON Formatter & Explainer

Format, validate, explore, and understand any JSON — paste it in and get instant clarity with AI-powered plain-English explanations.

## Features

- Auto-format and validate JSON with clear error messages
- Interactive tree view for exploring deeply nested structures
- Gemini-powered plain-English explanations of what your JSON means
- Clean, copyable output ready to paste back into your project

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Paste any JSON into the input panel
4. Use the Format, Validate, or Tree View buttons to explore
5. Click "Explain" to get a plain-English breakdown from Gemini

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
