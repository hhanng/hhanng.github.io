# Agent #55 - Reading Comprehension Trainer for ESL

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

**Live:** https://hhanng.github.io/agent-55-reading-comprehension-esl/

---

## Features

- 📋 **4 CEFR levels** — Beginner (A1–A2), Elementary (A2–B1), Intermediate (B1–B2), Advanced (B2–C1)
- 📖 **12 reading passages** (3 per level) with authentic topics from daily life to complex social issues
- ❓ **5 comprehension questions per passage** with immediate answer feedback and score tracking
- 🗃 **Vocabulary flashcards** — 60 key words from the passages, filterable by level, with flip animation
- 📊 **Progress tracking** — passages read, average quiz score, words seen, per-level progress bars

## Tech Stack

- Vanilla HTML / CSS / JS — single file, no dependencies, no API key
- localStorage (`esl55_` prefix) for all persistence
