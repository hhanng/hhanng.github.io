# Agent #59 — American Idioms & Slang

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

**Live:** https://hhanng.github.io/agent-59-american-idioms-slang/

---

## Features

- 🗂 **8 categories** — Everyday Speech, Work & School, Emotions, Food & Drinks, Sports, Money, Time, Relationships
- 📖 **120 idioms** — literal meaning, real meaning, and example sentence for each
- ✅ **Mark as Learned** — track your progress per category with localStorage
- 🎯 **Quiz mode** — 20 questions per round with 4-choice answers, score tracking, and wrong-answer review
- 📊 **Progress dashboard** — per-category progress bars, quiz history (last 5), best score

## Tech Stack

- Vanilla HTML / CSS / JS — single file, no dependencies
- localStorage (`idioms59_` prefix) for all persistence

## Usage

Open `index.html` in any browser — no build step, no API key needed.
