# Book Report Buddy

Instant summaries, character breakdowns, themes, key quotes, discussion questions, report outlines, and passage explanations — for 8 popular books, powered by Gemini.

## Features

- 8 popular books pre-loaded with full AI-generated analysis on demand
- Eight tools in one: summary, characters, themes, quotes, discussion questions, report outline, passage explainer, and custom questions
- Passage explainer lets you paste any excerpt and get a clear, student-friendly breakdown
- Great for homework help, book clubs, class discussion prep, and deeper reading

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Select a book from the pre-loaded list (or type any title)
4. Choose a tool: Summary, Characters, Themes, Quotes, Questions, Outline, or Explain Passage
5. Read your AI-generated analysis and use it as a starting point for your own work

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
