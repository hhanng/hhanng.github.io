## 📋 Description
Step-by-step math tutor for US middle/high school — 6 subjects, 170 bilingual EN/VI problems, and an interactive unit circle.

## ✨ Features
- 6 subjects: Pre-Algebra, Algebra 1 & 2, Geometry, Trigonometry, Statistics
- 170 problems with step-by-step solutions in both English and Vietnamese
- Interactive unit circle canvas (click any point → see sin/cos/tan in EN/VI)
- Canvas-based graph plotter for linear and quadratic equations
