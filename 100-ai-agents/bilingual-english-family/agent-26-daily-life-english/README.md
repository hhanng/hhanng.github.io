# Daily Life English Learner

**Category:** Mom's English

A bilingual English / Vietnamese app for real everyday situations — grocery shopping, doctor visits, banking, and more. Works completely offline with no API key needed.

## Features

- Scenario-based phrase sets covering grocery, doctor, bank, pharmacy, restaurant, and transportation
- Every phrase shown in English with a Vietnamese translation side by side
- Pronunciation tips and natural conversation examples for each scenario
- Fully standalone — no internet connection or API key required

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Choose a daily-life scenario from the menu (e.g., "At the Grocery Store").
3. Browse the phrase cards — tap a card to flip between English and Vietnamese.
4. Read the example conversation at the bottom to see phrases in context.
5. Practice out loud and move on to the next scenario when ready.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- No external API — fully standalone and offline-friendly
