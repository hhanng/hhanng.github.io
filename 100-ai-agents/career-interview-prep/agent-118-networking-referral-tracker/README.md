Complete networking system for CS students — contact tracker, outreach sequences, referral log, coffee chat prep, and network map.

- 3-message outreach sequence generator with company-specific customization
- Referral request tracker with follow-up reminders
- Coffee chat prep: research questions, intro script, thank-you note + SVG network map
