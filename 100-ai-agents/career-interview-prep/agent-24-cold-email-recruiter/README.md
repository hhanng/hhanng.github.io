# Cold Email to Recruiter

Generate 3 ready-to-send cold email variants to recruiters — each under 150 words, with a subject line and live word count — powered by the Gemini API.

Part of the [hhanng.github.io](https://hhanng.github.io) agent portfolio · Career

---

## What It Does

- Accepts recruiter name, company, target role, a key achievement, and preferred tone as inputs
- Generates 3 distinct email variants so you can choose the one that fits best
- Every variant includes a subject line and stays under the 150-word limit
- Live word count badge keeps each email tight and recruiter-friendly

## How to Use

1. Open `index.html` in your browser (or visit the live demo from the portfolio)
2. Enter the recruiter's name, company, and the role you're targeting
3. Add one standout achievement (the hook that makes you memorable)
4. Choose a tone (professional, conversational, bold, etc.)
5. Click **Generate Emails**
6. Compare the 3 variants, check the word count badges, and copy your pick

## Tech Stack

- HTML / CSS / Vanilla JavaScript
- [Gemini API](https://ai.google.dev/) (gemini-2.0-flash) for email generation
- No build step — runs entirely in the browser
