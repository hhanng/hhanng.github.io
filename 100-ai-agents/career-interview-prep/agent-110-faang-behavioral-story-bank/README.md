## 📋 Description
STAR story builder for 50 behavioral questions with company-specific customization for Google, Meta, Amazon, Apple, Netflix, and Microsoft. Stores your stories locally, tags by Leadership Principle, tracks coverage gaps, and exports a full prep sheet.

## ✨ Features
- 50 hardcoded behavioral questions across 5 themes (Leadership, Conflict, Problem Solving, Growth, Achievement)
- STAR form with writing prompts and live word count + timing per section (30–45s / 15–20s / 60–90s / 30–45s targets)
- Company customizer: reframe tips for Google / Meta / Amazon / Apple / Netflix / Microsoft
- Amazon LP mapper: tag stories to all 16 Leadership Principles with checkbox UI
- Progress tracker: X/50 questions with stories written, filtered by theme or company
- Mock interview mode: timed practice with self-rating (Easy/Medium/Hard), session summary flags weak stories
- Company readiness scores: coverage per company with progress bars
- Story gaps analysis: which themes need more stories, top 5 to write next
- Export full prep sheet — copy to clipboard or download as .txt
- All stories saved in localStorage

## 🛠 Tech Stack
- Vanilla HTML, CSS, JavaScript (single file, no dependencies)
- localStorage for all story data
