## 📋 Description
Validate startup ideas end-to-end — score your idea across 5 dimensions, research your market, build a SWOT analysis, and score your investor pitch before you talk to a single VC.

## ✨ Features
- **Idea Validator**: 5-section score (Problem Clarity, Market Potential, Competition, Founder Fit, Execution Risk) with auto-matched market category and actionable next steps
- **Market Research**: 30 market profiles with TAM, CAGR, key players, trends, investor criteria, winning startup case studies, and red flags — plus a Canvas competitor positioning map
- **SWOT Builder**: Smart pre-filled suggestions per quadrant, SWOT score, strength/weakness/opportunity/threat balance analysis, export to clipboard
- **Pitch Scorer**: 6-component pitch scoring with keyword detection, 20-item investor readiness checklist, 10-slide pitch deck outline generator
- All data saved in localStorage

## 🛠 Tech Stack
- Vanilla HTML, CSS, JavaScript (single file, no dependencies)
- HTML5 Canvas for competitor positioning map
- localStorage for all persistence
