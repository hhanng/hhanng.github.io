# 🏃 Agent #75 — Agile PM Toolkit

> Plan sprints. Kill blockers. Ship faster. Everything your team needs in one tab.

Part of the **[100 AI Agents Challenge](https://hhanng.github.io)** — building 100 single-file tools, one agent at a time.

🔴 **Live:** https://hhanng.github.io/agent-75-agile-pm-toolkit/

## What's inside
- Drag-and-drop Kanban board with story points and priority flags
- Sprint planner with burndown tracking and goal setting
- Retrospective board: What went well / What didn't / Action items
- Velocity tracker with 8-sprint history and forecast
- Fully offline — no Jira account required
