# 💰 Agent #96 — Personal Finance for CS Students

> Decode your offer letter, build a budget, and plan your path to financial independence.

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

## 🔴 Live: https://hhanng.github.io/agent-96-personal-finance-cs-students/

## Features
- TC calculator with vesting schedules, federal tax estimate, and cost-of-living city adjuster
- 50/30/20 budget analyzer with city-based expense ranges
- Compound interest chart (Canvas), 401k/RSU/HSA guides, index fund comparison
- 5-stage financial roadmap with net worth tracker

## Tech
Single-file HTML app — compound interest chart on HTML5 Canvas, all calculations client-side, state in localStorage.
