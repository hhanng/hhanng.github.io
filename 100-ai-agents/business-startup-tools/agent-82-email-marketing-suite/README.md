# ✉️ Agent #82 — Email Marketing Suite

> Draft, sequence, analyze, and template your email campaigns — all in one tab.

Part of the **[100 AI Agents Challenge](https://hhanng.github.io)** — building 100 single-file tools, one agent at a time.

🔴 **Live:** https://hhanng.github.io/agent-82-email-marketing-suite/

## What's inside
- Email Composer with live HTML preview, subject line analyzer (score + tips), and copy-to-clipboard HTML export
- Drip Sequence Builder: create named sequences with multi-step emails, configurable send delays, and per-step preview
- Campaign Analyzer: enter sent/delivered/opens/clicks/unsubs/bounces to get benchmarked rates with improvement tips
- 6 ready-to-use email templates (Welcome, Newsletter, Promo, Re-engagement, Abandoned Cart, Event Invite) with one-click "Use Template"
- All data persists in localStorage — no account needed
