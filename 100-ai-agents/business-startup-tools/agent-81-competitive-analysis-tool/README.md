# 🎯 Agent #81 — Competitive Analysis Tool

> Map the battlefield — score competitors, run SWOT, visualize positioning.

Part of the **[100 AI Agents Challenge](https://hhanng.github.io)** — building 100 single-file tools, one agent at a time.

🔴 **Live:** https://hhanng.github.io/agent-81-competitive-analysis-tool/

## What's inside
- Weighted competitive matrix: score any number of competitors on custom criteria with auto-calculated winner
- SWOT analysis builder for your company and each competitor, with per-quadrant item management
- Positioning map: plot competitors on a 2-axis canvas with configurable axis labels
- Auto-generated markdown report combining matrix totals, SWOT summaries, and positioning data
- All data persists in localStorage — no account needed
