# 📣 Agent #97 — Build in Public Playbook

> Your complete toolkit for building an audience while you build your product.

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

## 🔴 Live: https://hhanng.github.io/agent-97-build-in-public-playbook/

## Features
- Platform matcher: 5 questions → personalized platform recommendations
- 50 content templates (Project Updates, Learning, Career, Code, Engagement)
- Weekly planner with streak tracker and auto-suggest
- GitHub README generator, Twitter bio scorer, LinkedIn headline builder, portfolio tagline generator

## Tech
Single-file HTML app — all content generation is template-based, no external APIs. State persisted in localStorage.
