# 🧩 Agent #80 — Business Model Canvas

> Map your business model visually — 9 blocks, infinite ideas.

Part of the **[100 AI Agents Challenge](https://hhanng.github.io)** — building 100 single-file tools, one agent at a time.

🔴 **Live:** https://hhanng.github.io/agent-80-business-model-canvas/

## What's inside
- Interactive 9-block Business Model Canvas with drag-to-reorder sticky notes per block
- Multi-canvas support: create, rename, delete, and switch between multiple canvases
- 3 pre-filled examples (Airbnb, Spotify, SaaS Startup) with "Use as Template" one-click duplication
- GUIDE tab: definitions, key questions, and real-world examples for each of the 9 blocks
- EXPORT tab: markdown render of your full canvas + one-click clipboard copy + print
- All data persists in localStorage — no account needed
