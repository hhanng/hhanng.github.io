# Dynamic Programming Coach

An animated DP table visualizer for FAANG interview prep — step through 10 classic problems with live animations, pattern breakdowns, and a quiz to track mastery.

## Features

- 10 classic DP problems including Fibonacci, Knapsack, LCS, Coin Change, and more
- Step-by-step animated DP table fills so you can see the algorithm think
- Pattern reference guide connecting each problem to the underlying DP technique
- Gemini-powered quiz mode that checks your understanding and gives personalized hints

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Select a DP problem from the list
4. Watch the animated solution or step through it manually
5. Take the quiz to confirm you've internalized the pattern

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
