## 📋 Description
Spaced repetition flashcard system with pre-loaded FAANG DSA deck (80 cards) and ESL vocabulary deck (60 cards). Reviews scheduled by confidence rating — Again/Hard/Good/Easy — with retention tracked over time.

## ✨ Features
- SRS algorithm: Again=same day, Hard=1 day, Good=3 days, Easy=7 days
- 80 FAANG DSA cards: problems + optimal approach + complexity
- 60 ESL vocabulary cards: English + Vietnamese + pronunciation
- Custom deck: create, edit, delete your own cards
- 3D card flip animation (CSS perspective + rotateY)
- Stats: retention rate, streak, 30-day heatmap, card status breakdown
- Per-deck bar chart: New / Learning / Review / Mastered
- All data saved in localStorage

## 🛠 Tech Stack
- Vanilla HTML, CSS, JavaScript (single file, no dependencies)
- CSS 3D transforms for card flip animation
- localStorage for all SRS state
