# Exam Anxiety Coach

A fully offline calm-down toolkit for students before high-stakes exams. No API key, no account — just open it and breathe.

Part of the [hhanng.github.io](https://hhanng.github.io) agent portfolio · Study & CS

---

## What It Does

- **Box Breathing** — animated visual guide (inhale → hold → exhale → hold) to regulate your nervous system
- **Thought Reframing** — prompts that help you flip anxious thoughts into confident, realistic ones
- **Pep Talk Generator** — randomized encouraging messages to boost your pre-exam mindset
- **Pre-Exam Checklist** — interactive checklist to make sure you're physically and mentally prepared

## How to Use

1. Open `index.html` in your browser — no internet required after the page loads
2. Choose a tab based on what you need right now:
   - Feeling panicky? Start with **Box Breathing**
   - Spiraling thoughts? Try **Thought Reframing**
   - Need a confidence boost? Hit **Pep Talk**
   - Final prep check? Run through the **Checklist**
3. Use as many tabs as you need — there's no wrong order

## Tech Stack

- HTML / CSS / Vanilla JavaScript
- CSS animations for the breathing visualizer
- Fully standalone — zero external dependencies, no API required
