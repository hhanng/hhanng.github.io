# Recursion Visualizer

An animated call stack explorer for mastering recursion — step through Fibonacci, Merge Sort, and Tower of Hanoi with live stack frames and recursion trees.

## Features

- Three classic recursive algorithms: Fibonacci, Merge Sort, and Tower of Hanoi
- Live animated call stack shows exactly which function calls are active at each moment
- Recursion tree view maps out the full call hierarchy visually
- Step forward and backward through execution to build genuine intuition

## How to Use

1. Open `index.html` in your browser (no API key needed — fully standalone)
2. Select a recursive algorithm from the menu
3. Enter your input value (e.g., n = 5 for Fibonacci)
4. Press Play to watch the animation or use Step to move one call at a time
5. Study the call stack and tree until the pattern clicks

## Tech Stack

- Vanilla HTML, CSS, JavaScript
- No external API required — works completely offline
