# Quiz Generator from Notes

**Category:** Study & CS

Paste any set of notes or a topic and instantly get a full interactive quiz — multiple choice, true/false, or short answer — with instant scoring and explanations.

## Features

- Accepts raw notes, bullet points, or a topic name as input
- Generates MCQ, true/false, and short-answer questions in one mixed quiz
- Instant scoring with per-question feedback and correct-answer explanations
- Configurable number of questions and difficulty level

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Paste your study notes or type a topic into the input area.
4. Choose a question format, difficulty, and how many questions you want.
5. Click **Generate Quiz**, answer each question, and review your score.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
