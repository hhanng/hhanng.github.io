# OS Concepts Simulator

An interactive OS learning tool — simulate CPU scheduling, memory allocation, page replacement, deadlock detection, and disk scheduling right in your browser.

## Features

- CPU scheduling simulations: FCFS, SJF, Round Robin, and Priority scheduling with Gantt charts
- Memory allocation and page replacement algorithm visualizations
- Deadlock detection module with resource allocation graph
- Disk scheduling comparisons (FCFS, SSTF, SCAN, C-SCAN)

## How to Use

1. Open `index.html` in your browser (no API key needed — fully standalone)
2. Choose a module from the navigation (CPU, Memory, Deadlock, or Disk)
3. Enter your process or request parameters
4. Run the simulation and watch the animated results
5. Compare algorithms side by side to understand the trade-offs

## Tech Stack

- Vanilla HTML, CSS, JavaScript
- No external API required — works completely offline
