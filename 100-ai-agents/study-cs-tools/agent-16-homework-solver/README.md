# Homework Problem Solver

**Category:** Study & CS

Get step-by-step homework help that walks you through the reasoning — so you actually understand the solution, not just copy it.

## Features

- Step-by-step solution that narrates the thinking process at each stage
- Covers math, science, CS, history, and more — just paste the problem
- Hints mode available if you want to try it yourself first before seeing the full answer
- Includes a "Why does this work?" section to build lasting understanding

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Paste or type your homework problem into the input box.
4. Choose **Full Solution** or **Hints Only** mode.
5. Click **Solve** and follow each step at your own pace.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
