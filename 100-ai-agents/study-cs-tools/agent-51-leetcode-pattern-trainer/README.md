# #51 · LeetCode Pattern Trainer 🌸

> Learn the patterns behind every coding interview problem — not just the solutions.

**Category:** Study & CS &nbsp;|&nbsp; **Stack:** Vanilla HTML/CSS/JS · localStorage · No API needed

---

## Features

- 🧩 **12 core patterns** — Sliding Window, Two Pointers, Fast & Slow Pointers, Merge Intervals, Cyclic Sort, Tree BFS, Tree DFS, Binary Search, Dynamic Programming, Graph BFS/DFS, Backtracking, Two Heaps
- 📖 **Pattern breakdown** — "When to use", key insight, and a reusable code template for each
- 💡 **Practice problems** — 3–5 problems per pattern with difficulty tags (Easy / Medium / Hard), togglable hints, and full approach reveal
- 📊 **Progress tracking** — localStorage remembers which approaches you've reviewed; sidebar and footer dots update live

## How to Use

1. Open the app — pick a pattern from the sidebar (desktop) or dropdown (mobile)
2. Read the **When to Use** and **Key Insight** boxes
3. Study the **Code Template** as a reusable skeleton
4. Work through each practice problem — click **Show Hint** if stuck, then **Show Approach** to reveal the full walkthrough
5. Your progress saves automatically; reviewed problems are marked ✓

## Tech Stack

- Pure HTML + CSS + Vanilla JS — zero dependencies
- Google Fonts (Poppins + JetBrains Mono)
- `localStorage` for progress persistence
- Fully responsive (sidebar on desktop, dropdown on mobile)
