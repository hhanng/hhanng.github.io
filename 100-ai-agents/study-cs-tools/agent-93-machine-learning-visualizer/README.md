# 🤖 Agent #93 — Machine Learning Visualizer

> See gradient descent, KNN, K-Means, and neural networks move in real time.

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

## 🔴 Live: https://hhanng.github.io/agent-93-machine-learning-visualizer/

## Features
- 6 interactive visualizations: Linear Regression, Logistic Regression, KNN, K-Means, Neural Network, Decision Tree
- All animations run on HTML5 Canvas — no WebGL needed
- Algorithm cards, concept demos, and 20 flip-card interview questions
- Bias-variance tradeoff slider, confusion matrix calculator

## Tech
Single-file HTML app — all visualizations use Canvas 2D API with seeded random for reproducibility. No external ML libraries.
