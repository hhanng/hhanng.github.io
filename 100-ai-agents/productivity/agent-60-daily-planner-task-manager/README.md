# Agent #60 — Daily Planner & Task Manager

Part of the [100 AI Agents Challenge](https://hhanng.github.io)

**Live:** https://hhanng.github.io/agent-60-daily-planner-task-manager/

## Features

- **Today** — Add tasks with priority (high/medium/low) and category; check off completed tasks; filter by status or priority
- **Week** — 7-day grid (Mon–Sun) showing tasks per day with a completion % progress bar; click any day to add or view tasks
- **Goals** — Set weekly/monthly goals with deadlines and a progress slider (0–100%); mark complete when done
- **Stats** — Dashboard showing tasks completed today/this week, all-time completion rate, day streak, most productive day of week, and a weekly bar chart

## Usage

1. Open the live link above (or open `index.html` locally in any browser)
2. All data persists in `localStorage` under the `planner60_` prefix — no account needed

## Tech Stack

- Pure HTML + CSS + JavaScript (single file, no dependencies)
- `localStorage` for persistence
- Dark theme: `#0f1117` bg · `#4f8ef7` blue · `#4ade80` green
