# 🏋️ Agent #85 — PR & Strength Tracker

> Track every rep. Catch every plateau. Hit every personal record.

Part of the **[100 AI Agents Challenge](https://hhanng.github.io)** — building 100 single-file tools, one agent at a time.

🔴 **Live:** https://hhanng.github.io/agent-85-pr-strength-tracker/

## What's inside
- Workout log with auto-PR detection across 40 exercises
- Personal records board with 1RM estimates (Epley formula) and trend arrows
- Plateau detector — flags any lift stalled 3+ weeks with fix suggestions
- Progress charts: weight over time, weekly volume, estimated 1RM trend
- 4-week linear progression planner for the Big 3 lifts
