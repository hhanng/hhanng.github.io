📱 Telegram Reminder Bot Setup

Set up a daily 9 PM reminder so you never miss a check-in. No code required with Make.com.

1
Open Telegram → search @BotFather → send /newbot → follow prompts → copy your API token.
2
Send any message to your bot, then visit:
https://api.telegram.org/bot<TOKEN>/getUpdates
Find your chat_id in the JSON response (e.g. 123456789).
3
Replace YOUR_TOKEN and YOUR_CHAT_ID in this cURL command, then schedule it as a cron job (0 21 * * *) or paste it into Make.com as an HTTP module:
curl -s -X POST "https://api.telegram.org/botYOUR_TOKEN/sendMessage" \ -d chat_id=YOUR_CHAT_ID \ -d text="⏰ Daily check-in time! ✅ Did a LeetCode problem? ✅ System design reading? ✅ English practice? ✅ Networking outreach? ✅ Project / portfolio work? Log it 👉 [your app link]"
4
Cron schedule for 9 PM every day: 0 21 * * *. On Make.com use a Schedule trigger → HTTP → Make a request module. Free tier covers daily reminders.
