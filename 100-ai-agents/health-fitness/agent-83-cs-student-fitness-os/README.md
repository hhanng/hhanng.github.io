# 💻💪 Agent #83 — CS Student Fitness OS

> Stay active without leaving your desk — built for devs, by a CS student.

Part of the **[100 AI Agents Challenge](https://hhanng.github.io)** — building 100 single-file tools, one agent at a time.

🔴 **Live:** https://hhanng.github.io/agent-83-cs-student-fitness-os/

## What's inside
- 3 complete 6-day workout plans (Dorm Room, Gym, HIIT Cardio) with per-exercise checkboxes and progress bars
- Built-in rest timer with presets (30s–3min) for rest intervals and HIIT work sets
- 8 desk break exercises (eye relief, neck reset, cardio burst, box breathing, etc.) with step-by-step instructions and one-tap log
- Pomodoro break reminder using browser Notifications API
- Session tracker: log any workout with date, type, duration, energy (1–5), and notes
- Stats dashboard: total sessions, hours, streak, weekly chart, and workout type breakdown
- All data persists in localStorage — no account needed
