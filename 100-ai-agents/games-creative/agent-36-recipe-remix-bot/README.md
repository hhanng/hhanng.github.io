# Recipe Remix Bot

Give any recipe a makeover — remix it into a healthier, fusion, budget-friendly, or American pantry-friendly version with one click.

## Features

- Four remix modes: Healthier, Fusion, Budget-Friendly, and American Pantry Substitutes
- Works with any recipe — paste the text or describe the dish
- Gemini rewrites the full recipe with adapted ingredients and steps
- Perfect for Vietnamese families exploring American cooking or vice versa

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Paste or type your recipe (or just the dish name)
4. Choose a remix mode
5. Click Remix and get your new recipe instantly

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
