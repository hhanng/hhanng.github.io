# This Day in History Bot

Discover fascinating stories from any date in history — with a special Vietnam connection mode that surfaces the Vietnamese angle on world events.

## Features

- Enter any date and get rich, story-driven historical highlights from Gemini
- Vietnam Connection mode finds the Vietnamese perspective on global events
- Engaging narrative format — history as stories, not dry bullet points
- Great for daily learning, classroom use, or satisfying curiosity

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Pick any date using the date picker
4. Click "What Happened?" to get today's historical stories
5. Toggle Vietnam Connection mode for a special cultural lens

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
