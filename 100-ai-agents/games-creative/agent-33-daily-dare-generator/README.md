# Daily Dare Generator

Personalized daily challenges designed to push your comfort zone — with streak tracking and badges to keep you motivated.

## Features

- Gemini generates custom dares based on your interests and comfort level
- Streak counter tracks how many days in a row you've completed a dare
- Badge system rewards milestones and consistency
- All progress saved locally so your streaks survive browser restarts

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Tell the app your interests and how bold you're feeling today
4. Click "Generate My Dare" for today's challenge
5. Complete the dare, mark it done, and watch your streak grow

## Tech Stack

- Gemini API (Google AI)
- localStorage (progress persistence)
- Vanilla HTML, CSS, JavaScript
