# ESL Grammar Checker

Paste your writing and get gentle, level-matched AI grammar corrections — with error type highlights, a rewritten version, and progress tracking over time.

## Features

- Gemini corrects grammar gently with explanations tuned to your level (beginner/intermediate/advanced)
- Color-coded error highlights by type: grammar, word choice, punctuation, sentence structure
- Full rewritten version of your text so you can see the improved flow
- Progress tracker records your most common errors so you know what to practice

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Paste your writing into the text area
4. Select your English level
5. Click Check and review the highlighted corrections and rewritten version

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
