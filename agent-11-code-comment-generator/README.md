# Code Comment Generator

**Category:** AI Dev

Paste any function or file and watch inline comments and docstrings appear automatically — tuned to either a beginner-friendly or professional style.

## Features

- Adds inline comments to every meaningful line or block of code
- Generates complete docstrings/JSDoc/Pydoc with parameter and return descriptions
- Toggle between Beginner mode (plain English) and Pro mode (terse, technical)
- Preserves original code structure; only injects comments, never changes logic

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Paste your code into the editor panel and select the language.
4. Choose **Beginner** or **Pro** comment style.
5. Click **Comment Code**, then copy the annotated output.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
