# Resume Bullet Rewriter

Paste your weak resume bullets and get back 3 stronger rewrites per bullet — each with a punchy action verb, measurable metric, ATS-friendly keywords, and an explanation of why it's better.

Part of the [hhanng.github.io](https://hhanng.github.io) agent portfolio · Career

---

## What It Does

- Accepts one or more resume bullet points as input (paste the originals as-is)
- Generates 3 distinct improved versions for each bullet using Gemini
- Each rewrite includes a strong action verb, a quantified metric, and relevant ATS keywords
- Shows a "Why it's better" explanation so you understand the reasoning, not just the result

## How to Use

1. Open `index.html` in your browser (or visit the live demo from the portfolio)
2. Paste your existing resume bullets into the input area (one per line works best)
3. Click **Rewrite Bullets**
4. For each original bullet, review 3 improved options side by side
5. Pick your favorite version and copy it directly into your resume

## Tech Stack

- HTML / CSS / Vanilla JavaScript
- [Gemini API](https://ai.google.dev/) (gemini-2.0-flash) for bullet rewriting and analysis
- No build step — runs entirely in the browser
