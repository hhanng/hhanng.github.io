# American Pop Culture Explainer

Ask Gemini about any TikTok trend, meme, TV show, or slang — get a simple explanation with analogies, real examples, do's and don'ts, and a quick quiz.

## Features

- Ask about literally anything in American pop culture: trends, memes, shows, slang, fandoms
- Gemini explains in simple, relatable terms with analogies that make sense
- Do's and don'ts section so you know how to talk about it naturally
- Built-in quiz to check your pop culture knowledge after each explanation

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Type your question (e.g., "What is 'delulu'?" or "Explain Stranger Things")
4. Read the explanation — analogies, examples, and cultural context included
5. Take the mini quiz at the end to lock it in

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
