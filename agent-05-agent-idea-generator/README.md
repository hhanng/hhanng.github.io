# AI Agent Idea Generator

**Category:** AI Dev

Stuck on what to build next? Describe a category and difficulty level and this tool brainstorms a list of creative, actionable AI agent project ideas — powered by Gemini.

## Features

- Filter ideas by category (productivity, creativity, education, and more) and difficulty (beginner → advanced)
- Gemini-generated ideas with a short description and suggested tech stack for each
- Save or copy your favorite ideas with one click
- Regenerate for a fresh batch whenever inspiration runs dry

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Pick a category and difficulty level from the dropdowns.
4. Click **Generate Ideas** and browse the results.
5. Copy any idea to your clipboard or save it locally for later.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
