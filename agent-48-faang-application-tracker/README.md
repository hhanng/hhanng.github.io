# FAANG Application Tracker

A fully offline application tracker for tech job seekers — log every application, move it through 9 status stages, view summary stats, and export to CSV. No account, no backend, no API key needed.

Part of the [hhanng.github.io](https://hhanng.github.io) agent portfolio · Career

---

## What It Does

- Quick-pick buttons for FAANG companies (Meta, Apple, Amazon, Netflix, Google + more) so adding entries is fast
- Tracks 9 status stages: Applied → Phone Screen → OA → Technical → Final Round → Offer / Rejected / Ghosted
- Sortable table view so you can organize by company, role, date, or status at a glance
- Stats dashboard showing totals per stage and export to CSV for your own records

## How to Use

1. Open `index.html` in your browser — everything saves to `localStorage` automatically
2. Click a company button or type a company name, then fill in the role and date applied
3. Click **Add Application** to log it in the table
4. As your process progresses, update the status using the dropdown in each row
5. Check the stats dashboard for a real-time overview of where you stand
6. Click **Export CSV** anytime to download a copy of your tracker

## Tech Stack

- HTML / CSS / Vanilla JavaScript
- `localStorage` for persistent, offline storage
- Fully standalone — zero external dependencies, no API required
