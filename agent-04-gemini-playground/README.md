# Gemini API Playground

**Category:** AI Dev

An interactive sandbox for experimenting with the Gemini API directly in your browser. Tweak temperature and token limits in real time, explore prompt history, and jump-start ideas with built-in starter templates — no backend required.

## Features

- Live prompt testing with adjustable temperature and max-token controls
- Persistent prompt history so you can revisit and compare past runs
- Starter templates to get going instantly — creative writing, Q&A, summarization, and more
- Clean response display with copy-to-clipboard support

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Choose a starter template or type your own prompt.
4. Adjust temperature and token sliders, then hit **Generate**.
5. Browse your prompt history in the sidebar to compare results.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
