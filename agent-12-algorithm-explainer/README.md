# Algorithm Explainer

**Category:** Study & CS

Type any algorithm name and get a full breakdown: a real-world analogy, a step-by-step visual trace, Big O analysis, and a mini-quiz to lock in your understanding.

## Features

- Plain-English analogy that maps the algorithm to something you already know
- Step-by-step trace through a concrete example with highlighted state at each step
- Big O time and space complexity with a brief explanation of why
- Mini-quiz at the end to test retention before you move on

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Type an algorithm name (e.g., "merge sort", "Dijkstra's", "binary search").
4. Click **Explain** and read through each section at your own pace.
5. Take the mini-quiz at the bottom to check your understanding.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
