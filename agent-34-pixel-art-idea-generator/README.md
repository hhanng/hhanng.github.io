# Pixel Art Idea Generator

AI-generated pixel art concepts with Canvas previews, suggested color palettes, and a built-in editor to bring your ideas to life.

## Features

- Gemini generates detailed pixel art ideas with descriptions and color palette suggestions
- Canvas preview renders a visual mockup of each idea
- Built-in pixel art editor lets you start drawing immediately
- Save and export your creations as PNG files

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Describe a theme or subject (e.g., "retro space cat" or "cozy autumn scene")
4. Browse the generated ideas and pick one that inspires you
5. Open the built-in editor and start creating

## Tech Stack

- Gemini API (Google AI)
- HTML Canvas API
- Vanilla HTML, CSS, JavaScript
