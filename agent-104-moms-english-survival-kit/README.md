## 📋 Description
Everyday English for Vietnamese moms — bilingual EN/VI with scripts for doctor visits, grocery shopping, school pickups, and more.

## ✨ Features
- 10 life-situation tabs: Grocery, Doctor, Bank, DMV, Workplace, and more
- EN/VI flip cards + full conversation scripts
- Text-to-speech audio for every phrase
- Fill-in-blank quizzes + personal phrasebook saved locally
