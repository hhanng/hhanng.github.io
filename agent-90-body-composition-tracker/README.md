# 📊 Agent #90 — Body Composition Tracker

> Your weight is just one number. Track the full picture.

Part of the **[100 AI Agents Challenge](https://hhanng.github.io)** — building 100 single-file tools, one agent at a time.

🔴 **Live:** https://hhanng.github.io/agent-90-body-composition-tracker/

## What's inside
- Weekly check-in log: weight, body fat %, waist — with Cut/Bulk/Maintain/Recomp mode
- Live metrics dashboard: lean mass, fat mass, total change, BMI
- Progress charts: weight trend + 7-day moving average, body fat over time
- Rate of change indicator — flags if you're losing too fast or gaining too slow
- TDEE calculator, calorie targets, protein goals, US Navy body fat estimator
