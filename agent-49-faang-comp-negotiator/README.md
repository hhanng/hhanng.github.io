# FAANG Comp Negotiator

An AI-powered compensation negotiation coach for CS students and new grads — analyze offers, generate negotiation scripts, compare packages, and practice live coaching chats.

## Features

- Offer analyzer breaks down base, bonus, equity, and benefits to reveal your true total comp
- Gemini-generated negotiation scripts tailored to your offer and target company
- Offer comparator puts multiple packages side by side with a clear recommendation
- Live coaching chat where Gemini role-plays a recruiter so you can practice in real time

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Enter your offer details (company, role, base, bonus, equity, benefits)
4. Use the Analyzer to understand your TC, then generate a negotiation script
5. Add competing offers to the Comparator, or jump into Coaching Chat to practice

## Tech Stack

- Gemini API (Google AI)
- Vanilla HTML, CSS, JavaScript
