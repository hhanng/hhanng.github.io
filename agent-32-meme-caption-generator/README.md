# Meme Caption Generator

Pick a classic meme template, describe your situation, and get AI-generated captions with a live preview you can download as a PNG.

## Features

- 20 popular meme templates to choose from
- Gemini generates captions tailored to your topic or situation
- Live Canvas preview renders the meme with text overlaid on the image
- One-click PNG download so you can share immediately

## How to Use

1. Open `index.html` in your browser
2. Enter your Gemini API key when prompted
3. Select a meme template from the gallery
4. Describe what your meme is about
5. Click Generate, preview the result, and download your PNG

## Tech Stack

- Gemini API (Google AI)
- HTML Canvas API
- Vanilla HTML, CSS, JavaScript
