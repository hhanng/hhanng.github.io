# English Essay Writing Coach

An interactive essay writing coach covering all major essay types, with a built-in outline builder and writing prompts for practice.

## Features

- **Essay Types** — covers Argumentative, Expository, Narrative, Persuasive, Compare & Contrast, and more
- **Learn** — structured lessons on thesis statements, topic sentences, transitions, and citations
- **Builder** — fill in your essay type, topic, and thesis → get a full outline instantly
- **Practice** — curated writing prompts with type and difficulty filters

## How to Use

1. Open `index.html` in your browser (or visit the live site)
2. Start with **Essay Types** to find the type you need
3. Read the **Learn** tab for structure and examples
4. Use the **Builder** to generate an outline for your topic
5. Pick a prompt from **Practice** to start writing

## Tech Stack

- Vanilla HTML + CSS + JavaScript
- No dependencies, no API key
