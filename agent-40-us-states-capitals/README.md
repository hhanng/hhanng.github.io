# US States & Capitals Explorer

**Category:** Sis English / Study

Learn all 50 US states and their capitals with flashcards, a zoomable interactive map, and multiple quiz modes — including a shape-recognition quiz. Perfect for 8th graders preparing for geography tests.

## Features

- Flashcard deck for all 50 states and capitals with flip animations
- Interactive zoomable map — click any state to see its name, capital, and a fun fact
- Multiple quiz modes: name the capital, name the state, and identify the state outline by shape
- Score tracking and instant feedback on every answer

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Start with **Flashcards** to learn the states and capitals at your own pace.
3. Switch to the **Map** tab and click around to explore each state interactively.
4. Head to **Quiz** mode when you feel ready — pick standard or shape quiz.
5. Review your score at the end and repeat any missed states.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- SVG-based interactive US map
- No external API — fully standalone and offline-friendly
