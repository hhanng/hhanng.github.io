✍️ Good Commit Message Examples
# Format: :  (50 chars max)
# Body: explain WHY, not WHAT (wrap at 72 chars)

# ✅ GOOD EXAMPLES

feat: add user authentication with JWT
fix: resolve null pointer error on login page
docs: update README with deployment instructions
refactor: extract validation logic into helper
test: add unit tests for payment module
chore: upgrade dependencies to latest stable
style: format code with prettier
perf: cache API responses to reduce load time

# Bad → Good rewrites:
# ❌ "fixed stuff"        → ✅ "fix: resolve crash when cart is empty"
# ❌ "update"             → ✅ "docs: add API endpoint documentation"
# ❌ "wip"                → ✅ "feat: add draft order functionality (in progress)"
# ❌ "changes"            → ✅ "refactor: simplify auth middleware logic"

# Types: feat | fix | docs | style | refactor | test | chore | perf | ci
