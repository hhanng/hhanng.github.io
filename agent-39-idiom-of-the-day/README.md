# Idiom of the Day

**Category:** Sis English

A daily dose of American idioms with Vietnamese translations, origin stories, example sentences, and a mini-game to reinforce each one. No API key needed.

## Features

- A new featured idiom every day with its Vietnamese translation
- Origin story and cultural context for each idiom so it sticks in memory
- Example sentences showing the idiom used naturally in conversation
- Quick mini-game (fill-in-the-blank or match-the-meaning) to test recall

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Read today's featured idiom, its Vietnamese translation, and its origin story.
3. Study the example sentences to see it used in context.
4. Play the mini-game at the bottom to test yourself.
5. Browse previous idioms using the archive button whenever you want to review.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- No external API — fully standalone and offline-friendly
