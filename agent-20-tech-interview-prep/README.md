# Tech Interview Prep Bot

**Category:** Study & CS

Simulate a real tech interview session. Answer coding and system-design questions, get per-answer AI feedback, and receive an overall grade with actionable advice at the end.

## Features

- Realistic interview questions across data structures, algorithms, and system design
- Per-answer AI feedback on correctness, clarity, and code quality
- Configurable difficulty and role (frontend, backend, full-stack, data engineering)
- Final grade summary with a breakdown of strengths and areas to improve

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Select your target role and difficulty level.
4. Answer each question in the text or code editor provided.
5. Click **Submit Answer** for immediate feedback, then complete the session to see your overall grade.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
