# CS Concept Simplifier

**Category:** Study & CS

Enter any computer science term and get a jargon-free explanation, a relatable real-world analogy, and a short code demo — whether you're a complete beginner or brushing up for an interview.

## Features

- Jargon-free explanation written for the experience level you choose
- Real-world analogy that connects the concept to everyday life
- Short, runnable code demo illustrating the concept in action
- Follow-up question suggestions to deepen your exploration

## How to Use

1. Open `index.html` in your browser (or visit the live demo on the portfolio).
2. Enter your Gemini API key in the settings panel.
3. Type a CS concept (e.g., "recursion", "mutex", "hash table").
4. Select your experience level (Beginner / Intermediate / Advanced).
5. Click **Simplify** and work through the explanation, analogy, and code demo.

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
- No build step — open and go
