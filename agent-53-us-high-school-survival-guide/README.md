# US High School Survival Guide

Everything a new (or struggling) high school student needs to know — GPA, SAT/ACT, college prep, social life, and more — organized by grade.

## Features

- **Topics** — browse common confusing HS concepts: GPA, credit hours, AP classes, lunch periods, teacher letters of rec, and more
- **Guide** — detailed walkthroughs per topic with grade-specific advice (9th–12th)
- **Quiz** — test your knowledge on how US high school actually works
- **Checklist** — grade-by-grade to-do list so you never fall behind

## How to Use

1. Open `index.html` in your browser (or visit the live site)
2. Start with **Topics** to find whatever is confusing you
3. Read the **Guide** for a full explainer
4. Take the **Quiz** to reinforce the concepts
5. Use the **Checklist** to track your grade-level milestones

## Tech Stack

- Vanilla HTML + CSS + JavaScript
- No dependencies, no API key
